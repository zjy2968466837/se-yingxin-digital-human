# 部署指南（本地开发 → 云 ECS）

## 环境分层

同一套代码，三处配置不同，**代码零改动**，只切配置：

| 环境 | 数据库/Redis | 配置方式 |
|------|--------------|----------|
| 本地开发 | 本机 Docker（`docker-compose.yml`） | `application.yml` 默认值，连 `localhost` |
| 联调/演示 | 云 ECS 上的 Docker（`docker-compose.prod.yml`） | 环境变量 / `application-prod.yml` |
| 生产（课程可选） | 云数据库 RDS + 云 Redis | 只改连接串，代码同样不动 |

## 本地：WSL2 安装 Docker Engine（推荐方案）

```bash
# 1. WSL 内启用 systemd（若未启用）
sudo tee /etc/wsl.conf > /dev/null <<'EOF'
[boot]
systemd=true
EOF
# Windows 侧执行 wsl --shutdown 后重开终端

# 2. 安装 Docker Engine + compose 插件（Ubuntu）
sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 3. 免 sudo
sudo usermod -aG docker $USER   # 重新登录生效

# 4. 验证 + 启动基础设施
docker compose version
cd backend && docker compose up -d
```

> 队友用 Windows 想省事也可以装 Docker Desktop（WSL2 后端），效果等价。

## 云 ECS：部署数据库与 Redis

### 1. 准备密码文件（严禁提交 git）

在 ECS 上创建 `backend/.env.prod`：

```ini
MYSQL_ROOT_PASSWORD=换成强密码
MYSQL_PASSWORD=换成强密码
REDIS_PASSWORD=换成强密码
```

### 2. 启动

```bash
cd backend
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d
```

### 3. 安全组配置（关键）

ECS 控制台安全组**只放行**：

| 端口 | 来源 | 用途 |
|------|------|------|
| 22 | 你的 IP | SSH 运维 |
| 8080（网关）/ 80 / 443 | 0.0.0.0/0 | 对外服务 |
| ~~3306 / 6379~~ | **不开放** | 只走 ECS 内部网络 |

MySQL 和 Redis 在 `docker-compose.prod.yml` 中没有映射到宿主机公网端口，外部根本连不进来——这是故意的。临时调试用 SSH 隧道：

```bash
ssh -L 3306:localhost:3306 user@ecs-ip   # 本地连 localhost:3306 即通
```

### 4. 后端服务连云数据库的配置

Spring Boot 用 profile 区分，`application-prod.yml`（同样不入库，或全部改用环境变量）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/yingxin?useUnicode=true&characterEncoding=utf8mb4
    username: yingxin
    password: ${MYSQL_PASSWORD}
  data:
    redis:
      host: 127.0.0.1
      password: ${REDIS_PASSWORD}
```

启动时：`java -jar xxx.jar --spring.profiles.active=prod`。

后端服务与数据库同机部署时连 `127.0.0.1`；若后端跑在另一台机器，把 `127.0.0.1` 换成数据库 ECS 的**内网 IP**（同 VPC 免流量费且不暴露公网），并在数据库那台的安全组放行来源内网 IP。

### 5. 演示期建议

- 课程演示直接「一台 ECS 全家桶」：MySQL + Redis + 后端微服务 + Nginx（前端静态文件）一台机器搞定
- 数据库数据记得定期备份：`docker exec yingxin-mysql sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" yingxin' > backup.sql`（放 crontab）
- 若学校要求或预算允许，换云数据库 RDS + 云 Redis 更稳（自动备份、免运维），只需改连接串
