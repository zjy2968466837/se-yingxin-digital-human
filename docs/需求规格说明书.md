# 需求规格说明书 —— 大学生迎新导引服务数字人系统

> 版本：v1.0 草稿，基于立项材料整理，待团队评审

## 1. 引言

### 1.1 项目目的

面向高校新生报到全流程的 AI 数字人智能服务系统。以 3D 虚拟数字人 / 2D 形象数字人为交互入口，整合迎新政策、报到流程、校园导航、资助助学贷款、军训、宿舍、生活、社团、安全等信息，提供 7×24 小时语音/文字交互、主动引导、可视化办事指引，替代/补充线下迎新志愿者，实现一站式、无接触、高效率迎新服务。

### 1.2 技术（技术要求）

- **前端**：小程序 uniapp / 原生微信小程序；H5/PC 用 Vue3/React；音视频 WebRTC / 实时流播放（数字人）
- **后端**：微服务 / 云原生；RESTful API + WebSocket（实时交互）
- **数据库**：MySQL + Redis（缓存热点问答）
- **消息推送**：站内信 / 公众号模板消息

## 2. 核心功能需求

### 2.1 身份核验与个性化迎新

- 支持学号 / 身份证 / 人脸轻核验（对接学校统一身份认证）
- 自动识别：本科 / 研究生、学院专业、宿舍楼栋、报到批次
- 个性化欢迎语、专属报到清单、待办事项推送

### 2.2 报到全流程导引（核心）

- 步骤化引导：线上预报到→缴费→绿色通道→领物资→入住→人脸采集→校园卡激活
- 状态查询：已完成 / 待完成、办理地点、办公时间、联系人电话
- 材料清单：录取通知书、档案、党团关系、照片、户口迁移等自动提醒
- 异常处理：未缴费、材料缺失、暂缓报到、改期申请指引

### 2.3 智能问答（数字人主交互）

- 高频问答库：报到、军训、宿舍、食堂、图书馆、校医院、快递、医保、选课、一卡通、门禁、网络、电费水费等
- 意图理解：支持口语化提问（"在哪领被子""怎么充饭卡""助学贷款怎么弄"）
- 多轮对话：追问、澄清、补充信息
- 答案形式：文字 + 语音播报 + 图片 / 流程图 / 短视频 / 地图点位

### 2.4 校园 AR/3D 导航（关键体验）

- 室内 + 室外导航：校门→报到点→宿舍→食堂→超市→医务室→图书馆
- 支持路径规划、步行时间、公交 / 校内通勤车
- 数字人带路：语音播报"左转 50 米到达 XX 学院报到点"
- 地标讲解：建筑介绍、开放时间、楼层分布

### 2.5 资助与绿色通道服务

- 资助政策：国家助学金、助学贷款、勤工助学、困难补助
- 材料清单、办理入口、咨询电话、办理地点一键直达
- 缓交学费申请指引

### 2.6 生活服务聚合

- 宿舍报修、水电缴费、洗衣机、热水、门禁
- 食堂菜单、营业时间、优惠
- 校园网开通、营业厅位置、快递点
- 就医流程、医保报销、心理中心

### 2.7 安全与防诈骗教育

- 新生必看：刷单、网贷、冒充老师/辅导员、校园贷、行李防盗
- 安全答题 / 轻科普（数字人讲解）
- 紧急电话：保卫处、辅导员、校医院、报警

### 2.8 社团与入学适应

- 社团介绍、招新时间、加入方式
- 入学教育、军训安排、校规校纪
- 常用表格下载：请假、证明、补办卡等

### 2.9 管理后台（学校运维）

- 数字人话术配置、问答库管理
- 迎新信息发布、公告推送
- 数据统计：咨询热点、导航热点、用户量、问题未解决率
- 权限管理：学工、后勤、保卫、学院分权维护

### 2.10 多端适配

- 微信小程序 / 公众号（主入口）
- 迎新官网嵌入
- APP 内嵌（如有校园 APP）
- PC 端咨询台（迎新现场大屏数字人）

## 3. 非功能需求

- 性能：迎新高峰并发下问答响应 < 2s；数字人流媒体延迟可接受
- 可用性：新生无引导也能完成主要咨询（7×24）
- 安全：身份信息与对话记录加密存储，防爬防刷
- 可维护性：问答库后台可配置、无需发版更新；关键服务有单元测试
