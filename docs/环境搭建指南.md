# 环境搭建指南

> 新成员按本文档从零搭建开发环境，遇到问题在群里提 Issue。

## 一、需要安装的基础软件

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17 | 后端 Spring Boot 3 必须 |
| Node.js | ≥ 20 LTS | 前端（小程序 + 管理后台） |
| pnpm | 最新 | 前端包管理器，`npm i -g pnpm` |
| Maven | ≥ 3.9 | 后端构建（或用 IDE 内置） |
| Docker Desktop / Docker Engine | 最新 | 启动本地 Redis（开发缓存） |
| 微信开发者工具 | 最新 | 小程序调试（Windows/Mac） |
| IDE | IntelliJ IDEA（后端）+ VS Code（前端） | IDEA 学生邮箱可免费申请教育许可 |

**Windows 用户**：推荐直接在 Windows 装 JDK/Node/Docker Desktop 开发；也可以用 WSL2，二选一，团队内保持一致最好。

## 二、准备开发环境基础设施（云 MySQL + 本地 Redis）

```bash
cd backend
docker compose up -d
```

启动后：

- Redis：`127.0.0.1:6379`（本地 Docker，仅本机访问）

开发数据库统一使用 Azure 开发库（脱敏副本），请在本机配置 `backend/.env`（由 `backend/.env.example` 复制）：

- `MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_DB` / `MYSQL_USER` / `MYSQL_PASSWORD`
- `MYSQL_SSL_PARAMS`（建议保留默认 SSL 参数）

验证：`docker compose ps` 中 redis 容器为 healthy。

> 不用 Docker 的话，也可本机直装 Redis（Windows 可用 Memurai 或 WSL 内 Redis），但必须保持仅本机可访问。

> ⚠️ 本地与云上 Redis 密码不同：**本地无密码**，**云上有密码**（`REDIS_PASSWORD`）。服务代码里 `spring.data.redis.password` 留空即可连本地；上云后用 `application-prod.yml` 环境变量注入，不要在代码里写死。连云方式见《部署指南.md》。

## 三、启动后端微服务

```bash
cd backend
cp .env.example .env              # 首次执行，按实际开发库填写变量
mvn clean install -DskipTests          # 首次构建
cd services/gateway && mvn spring-boot:run -Dspring-boot.run.profiles=dev   # 网关先起
# 再分别启动其他服务（见 backend/README.md 各服务说明）
```

- 网关统一入口：`http://localhost:8080`
- 各服务 dev 环境应读取 `.env` 变量，不要硬编码数据库与 Redis 密钥
- 接口文档（springdoc）：`http://localhost:8080/{服务名}/swagger-ui.html`

## 四、启动前端

```bash
# 管理后台（Vue3）
cd frontend/admin-web
pnpm install
pnpm dev        # http://localhost:5173

# 小程序（uniapp，编译为微信小程序）
cd frontend/miniprogram
pnpm install
pnpm dev:mp-weixin
# 然后用微信开发者工具导入 dist/dev/mp-weixin 目录，填自己的测试 AppID
```

## 五、首次配置检查清单

- [ ] `java -version` 显示 17
- [ ] `docker compose up -d` 后 Redis healthy
- [ ] `.env` 已配置 Azure 开发库连接参数（未提交仓库）
- [ ] 网关启动后访问 `http://localhost:8080/actuator/health` 返回 UP
- [ ] 管理后台能打开登录页
- [ ] 微信开发者工具能加载小程序并渲染首页

## 七、常见问题

- **6379 端口被占**：本机装过 Redis 的先停掉服务，或改 `docker-compose.yml` 端口映射
- **微信开发者工具连不上后端**：真机调试需 https 与合法域名，开发期在开发者工具里勾选「不校验合法域名」
- **Maven 下载慢**：`settings.xml` 配置阿里云镜像（见 backend/README.md）
- **pnpm install 报错**：确认 Node ≥ 20；`npm i -g pnpm@latest` 重装
