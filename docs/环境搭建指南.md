# 环境搭建指南

> 新成员按本文档从零搭建开发环境，遇到问题在群里提 Issue。

## 一、需要安装的基础软件

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17 | 后端 Spring Boot 3 必须 |
| Node.js | ≥ 20 LTS | 前端（小程序 + 管理后台） |
| pnpm | 最新 | 前端包管理器，`npm i -g pnpm` |
| Maven | ≥ 3.9 | 后端构建（或用 IDE 内置） |
| Docker Desktop / Docker Engine | 最新 | 启动 MySQL + Redis，强烈推荐 |
| 微信开发者工具 | 最新 | 小程序调试（Windows/Mac） |
| IDE | IntelliJ IDEA（后端）+ VS Code（前端） | IDEA 学生邮箱可免费申请教育许可 |

**Windows 用户**：推荐直接在 Windows 装 JDK/Node/Docker Desktop 开发；也可以用 WSL2，二选一，团队内保持一致最好。

## 二、启动基础设施（MySQL + Redis）

```bash
cd backend
docker compose up -d
```

启动后：

- MySQL：`localhost:3306`，库 `yingxin`，用户 `yingxin/yingxin123`（本地开发用，密码见 `docker-compose.yml`）
- Redis：`localhost:6379`，无密码（仅本地）

验证：`docker compose ps` 两个容器都是 healthy 即可。

> 不用 Docker 的话，本机直装 MySQL 8 与 Redis（Windows 可用 Memurai 或 WSL 内 Redis），建同名库与账号即可。

## 三、启动后端微服务

```bash
cd backend
mvn clean install -DskipTests          # 首次构建
cd services/gateway && mvn spring-boot:run   # 网关先起
# 再分别启动其他服务（见 backend/README.md 各服务说明）
```

- 网关统一入口：`http://localhost:8080`
- 各服务配置文件 `application.yml` 已按本地 Docker 地址预置
- 接口文档（springdoc）：`http://localhost:8080/{服务名}/swagger-ui.html`

## 四、启动前端

```bash
# 管理后台（Vue3）
cd frontend/admin-web
pnpm install
pnpm dev        # http://localhost:5173

# 小程序（uniapp，编译为微信小程序）
cd frontend/miniprogram
pnpm install
pnpm dev:mp-weixin
# 然后用微信开发者工具导入 dist/dev/mp-weixin 目录，填自己的测试 AppID
```

## 五、首次配置检查清单

- [ ] `java -version` 显示 17
- [ ] `docker compose up -d` 后 MySQL/Redis healthy
- [ ] 网关启动后访问 `http://localhost:8080/actuator/health` 返回 UP
- [ ] 管理后台能打开登录页
- [ ] 微信开发者工具能加载小程序并渲染首页

## 六、数字人 / 第三方能力说明

> 申请 API Key 时把 Key 放 `.env` 或 `application-local.yml`（已在 `.gitignore` 中排除），**严禁提交到仓库**。

## 七、常见问题

- **3306 端口被占**：本机装过 MySQL 的先停掉服务，或改 `docker-compose.yml` 端口映射
- **微信开发者工具连不上后端**：真机调试需 https 与合法域名，开发期在开发者工具里勾选「不校验合法域名」
- **Maven 下载慢**：`settings.xml` 配置阿里云镜像（见 backend/README.md）
- **pnpm install 报错**：确认 Node ≥ 20；`npm i -g pnpm@latest` 重装
