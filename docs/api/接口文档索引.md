# 接口文档索引

> 由 `scripts/export_openapi.py` 从各服务的 `/v3/api-docs` 自动导出，**不要手改**。
> 新增/修改接口后：启动该服务 → 重新执行导出脚本 → 提交 JSON 与本索引。

## 查看方式

| 服务 | Swagger UI（直连） | OpenAPI JSON |
|---|---|---|
| `auth-service` | http://localhost:8100/swagger-ui.html | [openapi/auth-service.json](openapi/auth-service.json) |
| `qa-service` | http://localhost:8101/swagger-ui.html | [openapi/qa-service.json](openapi/qa-service.json) |
| `checkin-service` | http://localhost:8102/swagger-ui.html | [openapi/checkin-service.json](openapi/checkin-service.json) |
| `navigation-service` | http://localhost:8103/swagger-ui.html | [openapi/navigation-service.json](openapi/navigation-service.json) |
| `aid-service` | http://localhost:8104/swagger-ui.html | [openapi/aid-service.json](openapi/aid-service.json) |
| `life-service` | http://localhost:8105/swagger-ui.html | [openapi/life-service.json](openapi/life-service.json) |
| `content-service` | http://localhost:8106/swagger-ui.html | [openapi/content-service.json](openapi/content-service.json) |
| `admin-service` | http://localhost:8107/swagger-ui.html | [openapi/admin-service.json](openapi/admin-service.json) |

> Swagger UI 不在网关白名单内（开发规范 §4.2），**只能直连各服务端口**；
> 经网关 `8080` 访问会返回 401。生产环境应收敛 `springdoc.*.enabled=false`。
