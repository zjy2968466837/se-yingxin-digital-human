# 大学生迎新导引服务数字人系统

面向高校新生报到全流程的 AI 数字人智能服务系统。以 3D/2D 数字人为交互入口，整合迎新政策、报到流程、校园导航、资助、军训、宿舍、生活、社团、安全等信息，提供 7×24 小时语音/文字交互，一站式、无接触、高效率迎新服务。

## 系统组成

| 子系统 | 技术栈 | 目录 |
|--------|--------|------|
| 数字人交互端（小程序/H5） | uniapp / 微信小程序 | `frontend/miniprogram` |
| 管理后台（学校运维） | Vue3 + Vite | `frontend/admin-web` |
| 后端微服务 | Java 17 + Spring Boot 3 + Spring Cloud | `backend/services` |
| 基础设施 | MySQL 8 + Redis 7（Docker Compose） | `backend/docker-compose.yml` |

## 核心功能

1. 身份核验与个性化迎新（对接学校统一身份认证）
2. 报到全流程导引（线上预报到→缴费→绿色通道→领物资→入住→人脸采集→校园卡激活）
3. 智能问答（问答库 + 意图理解 + 多轮对话，语音/文字）
4. 校园 AR/3D 导航（室内外路径规划、数字人带路）
5. 资助与绿色通道服务
6. 生活服务聚合（报修、缴费、食堂、快递、就医）
7. 安全与防诈骗教育
8. 社团与入学适应
9. 管理后台（话术配置、问答库管理、数据统计、分权维护）
10. 多端适配（微信小程序/公众号、迎新官网嵌入、PC 大屏）
